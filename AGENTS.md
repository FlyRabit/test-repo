# AGENTS.md

## Cursor Cloud specific instructions

This is a **purely client-side React SPA** (小红书账号运营系统) — no backend, no database, no external API calls. All data is persisted in browser `localStorage`.

### Quick reference

| Action | Command |
|--------|---------|
| Install deps | `npm install` |
| Dev server | `npm run dev` (Vite, default port 5173) |
| Lint | `npm run lint` |
| Build | `npm run build` (`tsc -b && vite build`) |
| Preview prod | `npm run preview` |

### Notes

- **No test framework** is configured (no Jest, Vitest, Playwright, etc.). Manual browser testing is the only option.
- ESLint has 2 pre-existing errors and 1 warning in `src/store/useStore.tsx` (react-hooks/set-state-in-effect, react-hooks/exhaustive-deps, react-refresh/only-export-components). These are in existing code and do not block the build.
- The dev server should be started with `--host 0.0.0.0` for access within the cloud VM: `npm run dev -- --host 0.0.0.0`.
- Publishing is simulated locally; mock stats are generated by `generateMockStats()` in `useStore.tsx`.
