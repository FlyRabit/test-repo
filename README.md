# 小红书账号运营系统

一个功能完整的小红书账号运营管理系统，支持文案编辑、图片排版、一键发布及数据图表展示。

## 功能特性

- **文案编辑修改** - 编辑笔记标题和正文，实时字数统计
- **图片排版** - 上传图片、拖拽排序、添加图片说明，符合小红书 3:4 竖版规范
- **一键发布** - 发布预览、一键发布到本地（模拟）
- **数据图表** - 浏览量、点赞、评论、收藏、分享等数据可视化展示

## 技术栈

- React 19 + TypeScript
- Vite
- Tailwind CSS
- Recharts
- React Router

## 快速开始

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build
```

## 使用说明

1. **文案编辑**：在首页编辑笔记标题和正文
2. **图片排版**：切换到图片排版页，上传图片并调整顺序
3. **一键发布**：在发布页预览并点击发布按钮
4. **数据图表**：发布后可查看各笔记的数据统计和图表

数据将保存在浏览器 localStorage 中，刷新页面后仍可访问。
